# Crosscut admin console

This folder holds the administration-console design work. It is a desktop concept for managing the daily publishing calendar, puzzle readiness, player support, leaderboard reviews, economy support, and operational health.

- `publishing-calendar-metrics-concept.png` is the selected publishing-calendar direction, revised with operational metrics.
- `ADMIN-CONSOLE-RESEARCH.md` records the console research, proposed workflows, current backend limits, and the implementation boundary.

The concept uses demo data. It is not connected to production services.
